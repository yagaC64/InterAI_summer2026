# Contribution Scoreboard

This scoreboard tracks useful class collaboration.

Scores should reward real contribution quality. Do not award points for spam, duplicate edits, noisy commits, or changes that create cleanup work for others.

## Score Rules

| Action | Points | Notes |
| --- | ---: | --- |
| Add or correct your catalog entry | 1 | One-time starter contribution |
| Open a useful issue or suggestion | 2 | Must be specific and actionable |
| Submit a useful pull request | 2 | Small improvements count |
| Review a pull request with helpful feedback | 2 | Feedback must help the author improve the work |
| Merge-worthy improvement accepted | 3 | Award after the contribution is accepted |
| Help another classmate resolve a GitHub workflow issue | 2 | Document the help in an issue, PR, or class note |

When updating a score, keep the row sorted by GitHub handle unless the class decides to rank by total score.

Use the pull request description to explain the score change.
