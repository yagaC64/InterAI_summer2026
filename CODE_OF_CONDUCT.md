# Class Collaboration Standards

This repo is for learning, practice, and collaboration.

Expected behavior:

- Be respectful and constructive.
- Critique the work, not the person.
- Give feedback that helps the author improve.
- Keep public comments appropriate for a classroom and professional portfolio.
- Protect private information.

Unacceptable behavior:

- Harassment, insults, or personal attacks.
- Publishing another person's private information.
- Deliberately misleading score updates.
- Spam or low-effort activity intended only to gain points.

Maintainers may close issues, reject pull requests, remove inappropriate content, or adjust scores when needed.
