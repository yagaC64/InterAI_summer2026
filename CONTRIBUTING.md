# Contributing

Thanks for contributing to the InterAI Summer 2026 class repo.

## Add Your GitHub Handle

1. Create a branch named `add-handle-your-github-handle`.
2. Edit [CLASS_GITHUB_CATALOG.md](CLASS_GITHUB_CATALOG.md).
3. Add one row for yourself.
4. Open a pull request.
5. Use the pull request template and briefly explain what you changed.

## Keep Contributions Useful

Good contributions are specific, readable, and easy to review.

Please do:

- Use clear commit messages.
- Keep each pull request focused.
- Review your own diff before asking classmates to review it.
- Leave helpful comments when reviewing another student's work.
- Ask questions when a proposed change is unclear.

Please do not:

- Add private personal information.
- Edit another student's entry without a clear reason.
- Add fake accounts or joke rows.
- Create noisy commits just to raise your score.
- Publish secrets, API keys, screenshots with credentials, or private course material.

## Score Updates

Scores are tracked in [SCOREBOARD.md](SCOREBOARD.md).

Score changes should be explainable from GitHub activity such as issues, pull requests, reviews, or documented class help.
